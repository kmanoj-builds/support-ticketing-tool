# Support Ticketing Tool

A full-stack support ticket management application developed as part of my Full Stack Development internship at NeoStark Technologies.

## Project Overview

The application aims to help users create, view, and manage support tickets through a simple and responsive interface.

## Technology Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB

## Planned Features

- Create support tickets
- View all tickets
- View individual ticket details
- Manage ticket status
- Manage ticket priority
- Categorize support requests
